## 3. Keputusan Arsitektur untuk Refactor Bertahap

1. **Struktur proyek tetap dipertahankan** (`:app`, `:core:*`, `:streaming:*`, `:playback`, `:engine:local`) — modul-modul sudah bersih; kita refactor bertahap pada R1–R5 tanpa tulis ulang proyek.
2. **Alat Screenshot JVM:** Menggunakan **Robolectric `4.14.1` (`@GraphicsMode(NATIVE)`) + Compose `ui-test-junit4`** langsung di `:app` (berjalan di Windows & Linux CI tanpa emulator, mendukung konfigurasi `360dp`, `411dp`, `fontScale 1.0/1.3`, dan OLED on/off).
3. **Evaluasi Backdrop Blur (Kaca `Crystal`/`Liquid+`) — dicatat untuk R1:**
   - `RenderEffect` manual pada `Box` terbukti gagal memburamkan konten di belakangnya (**B1**).
   - Pilihan bersih berlisensi permisif: **`dev.chrisbanes.haze:haze-android:1.5.2` (Apache-2.0)** yang menerapkan real-time backdrop capture + blur di API 31+ tanpa FBO `Offscreen` layar penuh dan tanpa menyalin kode GPL.
   - Default tetap **`GlassStyle.SOLID`** sampai user memverifikasi kestabilan blur pada perangkat fisik.
