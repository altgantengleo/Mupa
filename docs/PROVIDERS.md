## 2. Rekomendasi Paket Maksimal 3 Provider (Untuk Dipilih User di Gate T0)

Sesuai syarat **maksimal 3 provider aktif**, **tanpa login/key/DRM**, **katalog Indonesia + internasional kuat**, dan **onboarding artis berfoto cepat**:

### Paket Rekomendasi (3 Provider):
1. **InnerTube (YouTube Music)** — **Stream Primer + Radio (`next` / `RDAMVM`) + Katalog** *(sudah ada, diperluas dengan endpoint `next` radio & continuation)*.
2. **Deezer Public API** — **CatalogProvider (Metadata + Foto Artis HD untuk Onboarding & Cari Paralel)** *(0 dependensi baru, 5/5 artis ID+global termasuk Tommy J. Pisa & yung kai dengan foto HD)*.
3. **iTunes Search API (`country=ID`)** — **CatalogProvider (Metadata Lagu/Album Cepat + Cover HD + Durasi Presisi)** *(0 dependensi baru, 5/5 artis ID+global, sangat membantu pencocokan durasi ±3 dtk lintas provider)*.

> **Catatan tentang JioSaavn:** Sudah ada di modul `:streaming:jiosaavn` sebagai fallback stream cadangan (tidak perlu dihapus bila ingin tetap menjaga fallback stream kedua untuk pop global saat InnerTube bermasalah, ATAU bisa diganti/dinonaktifkan dari 3 slot aktif sesuai pilihan user).

**Status:** **BERHENTI di T0** — menunggu konfirmasi user memilih maksimal 3 provider sebelum menulis kode provider baru (T1–T4).
